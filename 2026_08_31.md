- ## Två firewalls
- https://ubuntu.com/server/docs/how-to/security/firewalls/
- https://www.oracle.com/cloud/networking/network-firewall/
- Varför två firewalls?
	- Ubuntu = ufw (Uncomplicated Firewall)
		- Intern Firewall för Linux
		- Som att ha låsta dörrar i byggnaden
	- Oracle = OCI Network Firewall
		- Network Firewall kan används som skydd mot andra resurser på samma nätverk
		- Network Firewall är som att istället för att ha två företag i samma byggnad där man kan gå igenom så har företagen egna byggnader så det är svårare att ta sig in.
		- VCN1 - Företag 1
		- VCN2 - Avgränsning mellan Företagen
		- VCN3 - Företag 2
